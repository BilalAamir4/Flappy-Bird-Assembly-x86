# 🐦 Flappy Bird x86

A Flappy Bird clone built entirely in 8086 Assembly Language, 
running on the emu8086 emulator.

## 🎮 Gameplay
- Press Space to flap
- Avoid the pipes
- You have 3 lives
- Score increases with every pipe you clear

## ⚙️ Difficulty Levels
- 🟢 Easy (default) — slow pipes, wide gaps
- 🟡 Medium — faster pipes, smaller gaps  
- 🔴 Hard — fastest pipes, tightest gaps

## 🏆 Leaderboard
- Enter your name before playing
- Top scores saved to file
- Leaderboard displayed after Game Over

## 🛠️ Built With
- 8086 Assembly Language
- emu8086 Emulator
